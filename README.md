# MoneyBook

WinUI 3와 C++/WinRT로 작성한 간단한 로컬 가계부입니다.

## 기능

- 날짜, 수입/지출 구분, 내용, 금액 입력
- 총수입·총지출·잔액 자동 계산
- 거래 내역 표시 및 선택 삭제

## 개발 환경

- Windows 10 1809 이상 또는 Windows 11
- Visual Studio 2022
- **Desktop development with C++**, **Windows application development** 워크로드
- Windows App SDK 1.6

`MoneyBook.sln`을 Visual Studio에서 열어 사용할 수 있습니다.

> 현재 요청에 따라 이 환경에서는 빌드 또는 실행을 수행하지 않았습니다.
